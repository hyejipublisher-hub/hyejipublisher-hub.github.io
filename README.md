# Hyeji Publisher GitHub Pages

이 저장소는 Hyeji Publisher의 개발자 웹사이트, 개인정보처리방침,
고객지원 페이지 및 AdMob app-ads.txt 파일을 게시하기 위한 저장소입니다.

## 업로드 전 필수 수정

다음 두 파일에서 `YOUR_EMAIL@example.com`을 실제 Play Console 개발자 문의 이메일로 바꾸세요.

- privacy-policy.html
- support.html

## 권장 저장소 이름

GitHub 사용자 이름이 `hyejipublisher-hub`이라면 저장소 이름은 반드시 다음으로 만드세요.

`hyejipublisher-hub.github.io`

이렇게 해야 사이트 주소와 app-ads.txt 주소가 다음처럼 루트에 생성됩니다.

- https://hyejipublisher-hub.github.io/
- https://hyejipublisher-hub.github.io/app-ads.txt
- https://hyejipublisher-hub.github.io/privacy-policy.html
